# 3D / 2D 佈局規格（Phase 5）

- 程式：`lib/three/constants.ts`（所有示意值）、`lib/three/layout.ts`（佈局計算，輸出每個零件的 bounding box）、`components/FitPreview3D.tsx`（只負責畫 box）、`components/FitPreview2D.tsx`（同一份佈局的正視圖）
- 3D 是示意，不是 CAD。但**方向、相對大小、裝不裝得下**必須與真實尺寸及右側報告一致
- 有官方數值就用官方數值；沒有的位置用 `constants.ts` 的示意值，每項註明依據，並列在 `docs/pending.md` 的 L 段

## 1. 座標系與單位

| 軸 | 方向 | 原點 |
|---|---|---|
| x | 前後，**往前面板為正** | 機殼後方內壁（I/O 與擴充槽擋板所在的面）x = 0 |
| y | 上下，往上為正 | 機殼內部底面 y = 0 |
| z | 左右，**往側透玻璃為正** | 主機板托盤（tray）面 z = 0；背板走線空間在 z < 0 |

- 佈局計算全部用 **mm**。換算成 three.js 單位只在 `toSceneUnits()` 一個函式裡做，3D 元件內不出現未換算的數字
- 鏡頭預設在側透玻璃那一側（+z）往 −z 看：前面板在右、後方 I/O 在左

## 2. 機殼

- 外觀尺寸取自 `case.external`（depth → x、height → y、width → z）。缺值時用示意外觀尺寸，畫面標「示意尺寸」
- 內部空間 = 外觀扣掉示意壁厚 `CASE_WALL_MM`（每面）
  - x：`[0, external.depth − 2 × 壁厚]`，前面板內側在最大 x
  - y：`[0, external.height − 2 × 壁厚]`
  - z：背板內側在 `−走線空間`（官方 `cableSpaceMm`，缺值用示意值），側透玻璃內側 = 背板內側 + `external.width − 2 × 壁厚`
- 電源倉：`y ∈ [0, PSU_SHROUD_HEIGHT_MM]`，全深全寬（示意；ITX 機殼也畫，見 pending）
- **官方上限面**（虛線 / 半透明面），與報告採用的條件一致：
  - 顯卡長度上限面：`x = 報告 R02 採用的上限`（顯卡後端在 x = 0，所以面的位置 = 上限值）
  - 塔散高度上限面：`z = 主機板正面 + 報告 R05 採用的上限`
  - 電源長度上限面：`x = 報告 R10 採用的上限`（電源後端在 x = 0）
  - 顯卡高度上限面（有官方值時）：`z = 主機板正面 + R04 上限`

## 3. 主機板

- 尺寸：`motherboard.dimensions`（heightMm → y、depthMm → x）；缺值時用板型標準尺寸示意：ATX 305 × 244、M-ATX 244 × 244、Mini-ITX 170 × 170、E-ATX 305 × 277
- **所有板型的後方上緣（I/O 那一角）對齊同一個基準點**：`x = BOARD_REAR_X_MM`、`y = 內部高度 − BOARD_TOP_GAP_MM`。板子由基準點往下（−y）、往前（+x）延伸，小板型自然往上後縮
- 主機板裝在托盤上、面朝側透玻璃：背面 `z = BOARD_STANDOFF_MM`，正面 `z = 背面 + PCB_THICKNESS_MM`
- 板上元件位置（相對基準點：`dx` 往前、`dy` 往下），依板型設定在 `BOARD_FEATURES`：
  - CPU 插槽中心與尺寸
  - 第一條 PCIe x16 槽的位置（`slotDy`）
  - RAM 槽：數量、起始 dx、間距，長邊沿上下方向（DIMM 長 133.35 mm）

## 4. 顯卡

### 4.1 橫插（`gpuMountOrientation` 為 horizontal / both / 缺值）

實際裝機時主機板直立，顯卡插進 PCIe 槽後 **PCB 與主機板垂直**，大平面朝上下、風扇朝下：

| 顯卡尺寸 | 軸 | 範圍 |
|---|---|---|
| 長度 `lengthMm` | x | `[0, lengthMm]`：後端 = 擋板（機殼後方內壁），往前面板延伸 |
| 厚度 `thicknessMm` | y | `[slotY − thicknessMm, slotY]`：由第一條 x16 槽往下 |
| 高度 `heightMm` | z | `[主機板正面, 主機板正面 + heightMm]`：由插槽往側透玻璃突出（與 schema R04「由 PCIe 槽往側板方向」一致） |

- `slotY = 基準點 y − slotDy`（第一條 x16 槽）
- 風扇畫在底面（−y）

> **與任務原文的差異**：任務原文寫「高度沿上下、大平面與主機板平行、厚度朝玻璃」，這是**直立安裝**的方向，與實際橫插不符，也和同段的「風扇朝下」矛盾（風扇在大平面上）。照原文畫的話，顯卡高度與側板上限（R04）的畫面會和報告不一致，所以採用上表的物理方向，列入 pending L-01 待確認。

### 4.2 直立（`gpuMountOrientation` = vertical）

大平面朝側透玻璃：長度 → x（後端在 x = 0）、高度 → y（由電源倉頂往上）、厚度 → z（由示意的直立支架面往玻璃）。位置全部是示意值（`VERTICAL_GPU_*`），風扇朝玻璃。

## 5. 散熱

- **塔散**：底座在 CPU 插槽中心，高度沿 z 由主機板正面往玻璃（`[主機板正面, 主機板正面 + heightMm]`）；`depthMm`（沿氣流）→ x、`widthMm` → y
- **水冷排**（排厚 + 風扇厚）：
  - 前置：排長沿 y、排寬沿 z、厚度沿 x。報告 R02 採用「前置水冷」條件時，排的後面貼在顯卡長度上限面上（官方上限就是由此量測），否則前面貼前面板內側
  - 上置：排長沿 x（由後方往前）、排寬沿 z、厚度沿 y，貼在內部頂面下
- **出廠前置風扇**（`includedFans.front`，使用者沒有選前置水冷時才畫）：每顆尺寸沿 y、z，厚度沿 x（官方沒寫厚度用示意 25 mm）。R02 採用「前置裝風扇」條件時貼在顯卡長度上限面，否則貼前面板內側
- 水冷頭畫在 CPU 插槽上（示意）

## 6. 電源

- 放在電源倉內：長度 `lengthMm` 沿 x 由後方內壁往前（`[0, lengthMm]`），高與寬用 ATX / SFX 規格的標準外形（ATX 150 × 86、SFX / SFX-L 125 × 63.5）
- z 置中於機殼內部寬度

## 7. 裝不下時

- 零件**照真實尺寸畫，不截短、不縮放**
- 超出官方上限面的部分另外畫一個 Incompatible 顏色的「衝突區」box：
  - 顯卡前端超過顯卡長度上限面 → `x ∈ [上限, 顯卡前端]`
  - 顯卡與前置風扇 / 水冷排的重疊
  - 塔散頂端超過塔散高度上限面
  - 電源前端超過電源長度上限面
- 零件本身依報告的狀態上色（Safe / Info / Warning / Incompatible / Unknown）
